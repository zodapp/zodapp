# 入れ物の欄を「触った」「変えた」にする

今の仕様は [入れ物の欄の「触った」「変えた」](../../packages/zod-form-react/docs/container-touch.ja.md) にあります。

## 目的

入れ物（object・intersection・array・record）の path に出るエラー（path を指定しない `.refine()` など）で、2 つの不具合があった。

- 子の欄を離しても入れ物の欄は触ったことにならず、送信するまでエラーが出なかった
- 送信でエラーを出したあと子の欄を直しても、入れ物の欄の onSubmit のエラーが消えず、送り直せなかった。欄の onSubmit を消すのはその欄自身の検証だけで、入れ物の欄には欄ごとの検証が無いため

## 決めたこと

- **入れ物の部品は、子の欄のあとに目印（`ContainerMarker`）を置く。** 目印を前の欄を検証するしくみに登録し、入れ物より後ろの欄に入ったとき・最後の欄を離したときに、入れ物の欄を触ったことにする。欄を離したことは `focusout` で受け取り、部品ごとに onBlur をつながない（使っている部品が多いため）
- **同じ path の外側の部品がいれば、外側だけが置く。** intersection の両側や union の腕が置くと、左側の最後の欄を離しただけで intersection を触ったことになるため
- **入れ物の値が変わったら、入れ物の欄だけを検証する（`skipFormValidation`）。** フォーム全体の検証は子の欄の入力ですでに走っているので、入れ子の数だけ重ねないため

扱わないこと：根の `.refine()`（フォーム全体のエラーで欄には出ない）、最後の欄以外から余白をクリックしたとき（送信すれば出る）。
