# enum の badge 表示：選択済みの値もバッジにする

今の仕様は [バッジで出す選択](../../packages/zod-form-mantine/docs/badge.ja.md) にあります。

## 目的

`uiType: "badge"` の enum で、ドロップダウンの選択肢はバッジで出るのに、選択済みの値は素の文字で出ていた。Mantine の `Select` の `renderOption` はドロップダウンの各行にしか効かず、入力欄が `<input>` なので、選択済みの値の描き方を差し替えられない。あわせて、選択済みの状態で打ち込むと既存の文字に足されていた（「進行中進」）。

## 決めたこと

- **Combobox で組んだ専用の部品（`BadgeSelect`）にする。** 閉じている間はバッジを出し、ドロップダウンを開いている間は文字入力に切り替える。入力欄は空から始まり、選択済みのラベルは placeholder で出すので、既存の文字に足されない。切り替えの条件は、フォーカスではなくドロップダウンの開閉にする（フォーカスにすると、選んだ直後に薄い文字だけになり、選べていないように見えた）
- **読み取り専用と複数選択もバッジにする。** `multipleEnumBudge` を `multipleEnumBadge` に改名した（旧綴りの互換は残さない）
- **バッジの文字色を、背景色から決める。** Mantine の `light` は、濃さ付きの色（`"blue.6"`）でも文字色を濃さなし用のままにするので、コントラストが 1〜3 程度になっていた。Mantine の `autoContrast` は `filled` にしか効かず白か黒の二択で、色は RGB で指定されることもあるので、濃さの番号に頼る規則も使えない。そこで、背景を OKLCH にして、同じ色相で一定だけ暗い色を文字にし、暗すぎるときは白にする。明るさの差と白にする境目は、全色相×濃さの比較を見て決めた
