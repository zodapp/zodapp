# 日本語だけの文書を英語にする

今の決まりは [AGENT.md](../../AGENT.md) の「Where documents go」にあります。

## 目的

PR #38 で README は日英 2 本になったが、README からリンクしている仕様（`packages/*/docs/*.ja.md`）、一部のアプリの README、開発者向けの文書は日本語だけで、英語 README からは「(Japanese)」と断ってリンクしていた。英語の利用者が仕様まで読めるようにし、英語を正とする。

## 決めたこと

- **利用者向けの文書は日英 2 本にする。** 英語の `<名前>.md` を正とし、日本語の `<名前>.ja.md` を隣に置く。直すときは両方を直す。冒頭に `[日本語]` / `[English]` の相互リンクを置き、英語版同士は英語版に、日本語版同士は日本語版にリンクする
- **開発者・エージェント向けの文書（AGENT.md、`docs/releasing.md` など）は英語 1 本にする。** 2 本あると片方だけ直されてずれるため
- **`docs/plans/`・`docs/archive/` は日本語のまま。** プランは日本語で管理する
- **コード例・コード中のコメント・UI に出る日本語の文言は訳さない。** アプリで日本語に固定されている UI の文言は、日本語のまま英語の説明を添える。ライブラリの UI の文言は `en` の辞書の文言を使う
