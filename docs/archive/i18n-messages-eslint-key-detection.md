# ESLint ルール `comment` のキーを、文字列の形で見つける

今の仕様は [eslint-plugin-i18n-messages の README](../../packages/eslint-plugin-i18n-messages/README.ja.md) にあります。

## 目的

ルール `comment` は、`msg`・`msgKey` という名前の関数の第 1 引数だけを見ていたので、キーを別の関数に渡すとき、関数の引数でない場所（エラーマップが返すタプルなど）、呼び出す側が名前でない式（`useMsg()("…")`）のキーを見逃していた。また、キーの後ろの普通のコメントを `--fix` で消し、キーを消すとコメントだけが残った。

## 決めたこと

- **関数の名前ではなく、文字列の形でキーを見つける。** 文字列の全体が「辞書のプレフィックス＋キーの残り（＋`?params`）」に合えば、キーとみなす。オブジェクトのキー、import の source、型の位置の文字列は見ない
- **ルールが書くコメントに目印 `i18n:` を付ける（`/* i18n: 文言 */`）。** ルールは目印付きのコメントだけを扱い、普通のコメントは読みも消しもしない。キーから離れて残った目印付きのコメントは `orphan` として消す
- `callees` オプションは消す（未公開なので互換は残さない）

`` `zod.${code}` `` のように組み立てたキーは確かめられない。
