# バッジで出す選択（`uiType: "badge"`・`"multipleEnumBadge"`）

enum と literal の union は、`uiType: "badge"` で選択肢と選択済みの値をバッジで出します。複数選択は、配列に `uiType: "multipleEnumBadge"` を付けます。`uiType` の無い enum は Mantine の `Select` のままです。

## 一つ選ぶ（`BadgeSelect`）

Mantine の `Select` は入力欄が `<input>` で、選択済みの値の描き方を差し替えられません。そこで、Combobox で組んだ部品（`BadgeSelect`。`@zodapp/zod-form-mantine-lite` の utils）で描きます。AutoForm・AutoSearch の部品と、ReactiveAutoForm の部品の両方で使います。

- 閉じている間は、入力欄の位置に選択済みの値をバッジで出します。入力欄の文字は空です
- ドロップダウンを開いている間（フォーカス・クリック・打ち込み）は、文字入力に切り替え、選択済みのラベルを placeholder で出します。入力した文字で、ラベルと値を部分一致で絞り込みます。入力欄は空から始まるので、既存の文字に足されることはありません
- 選ぶか閉じると、フォーカスが残っていてもバッジに戻します
- 値があれば × で消せます（空の値は `emptyValueOf`）。値が無ければシェブロンを出します
- 選べない選択肢（`unlisted: "keep"` の「（不正な値）」）は、表示するが選べません。一致する選択肢が無ければ「見つかりません」を出します
- キーボードの操作（上下・Enter・Esc）は Mantine の Combobox に任せます

読み取り専用の表示もバッジにします。値が無ければ空です。

## 複数選ぶ

`MultiSelect` の選択済みのピルを、× で外せるバッジにします（`renderPill`）。読み取り専用の表示もバッジを並べます。

## バッジの色

バッジは `variant="light"` で、選択肢の `color`（既定 `gray`）を使います。Mantine の `light` は、濃さ付きの色（`"blue.6"`）でも文字色を濃さなし用のままにするため、読みにくくなります。そこで、文字色を背景色から決めます（`badgeColor.ts`）。選択肢・選択済み・読み取り専用・複数選択のピル・表の computed のバッジ（`renderComputedValue` の `type: "badge"`）で同じです。

- **濃さなしのテーマ色**（`"blue"` など）：Mantine の `light` のまま
- **濃さ付きのテーマ色と RGB の指定**（`"blue.6"`、`#3b82f6`・`rgb()`・`hsl()`）：
  1. 背景は指定した色そのもの
  2. 背景を OKLCH にし、暗い文字の候補を作る。色相は背景と同じ、明るさは背景の L − 0.45、鮮やかさは `min(0.35 × 文字の L, 背景の C × 8)`（灰色の背景なら灰色の文字）。sRGB に収まらなければ鮮やかさだけ下げる
  3. 候補の L が 0.30 未満か、白の方がコントラスト比が高ければ白。それ以外は 2 の色
- **計算できない色**（透明度のある色、`var()`、名前の CSS 色）：Mantine の `light` のまま

L − 0.45 は、Mantine の濃さ 9 の文字色が、どの色相・濃さでも背景より 0.35〜0.5 暗かったことから決めた一定値です。白にする境目（0.30）は見た目で選んだ値で、黄・緑の中間などでコントラスト比が 4.5 を少し割るところは許容しています。
